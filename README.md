# ORBIT · два приложения для Windows

**Orbit Settings** — окно настроек. Здесь можно выбрать микрофон, положение островка, модель ИИ, озвучку, игровой режим и макросы MSI, посмотреть демо, запустить или остановить помощника. **Orbit Assistant** — фоновый голосовой помощник с компактным островком, локальным Vosk или Whisper для распознавания речи, Gemini/OpenAI для ответов и Fish Audio/Piper/Edge TTS для озвучки.

## Как получить два EXE

Сборка выполняется на **Windows 10/11 x64** с Python **3.11 или 3.12**. PyInstaller собирает исполняемые файлы для той системы, на которой запущен. Команды выполняются в папке с `settings_app.py`, `assistant_app.py` и `requirements.txt`:

```powershell
python -m pip --version
python -m pip install --user -r .\requirements.txt pyinstaller
python .\build_windows.py
```

Можно вместо двух последних команд открыть `build-exe.bat`. Если в системном Python отсутствует `pip`, сначала восстанови его установщиком Python (Modify/Repair); незавершённое `.venv` с `No module named pip` сборку не выполнит. Для быстрой активации используется малая локальная модель Vosk; она скачивается при первом запуске, если файла нет. Созданные файлы:

Если сборка остановилась с `PermissionError: [WinError 5]` именно внутри `subprocess.Popen` / `_winapi.CreateProcess`, Windows отказала в запуске дочернего `python.exe`. Это отдельная проблема от установки пакетов; проверь «Безопасность Windows → Журнал защиты». Для точной проверки в PowerShell: `python -c "import subprocess,sys; subprocess.run([sys.executable,'-I','-c','print(123)'],check=True)"`. Если и эта команда выдаёт WinError 5, локальная сборка не начнётся до устранения запрета. Отключать защиту целиком не требуется: ниже есть вариант с GitHub Actions.

Если сборка на твоём ПК пока не получается из-за сломанного `pip`, в проекте также лежит `.github/workflows/build-windows.yml`: при загрузке **исходников без `.env` и ключей** в свой репозиторий GitHub запусти Actions → Build Orbit Windows EXE → Run workflow, затем скачай артефакт `ORBIT-Windows`. Это запасной способ получить те же два файла на Windows-сервере сборки.

- `dist\Orbit Settings.exe` — настройка и кнопки управления.
- `dist\Orbit Assistant.exe` — сам помощник. Оба файла держи рядом: кнопка запуска в настройках ищет второй EXE в той же папке.

Режим одного файла PyInstaller распаковывает компоненты во временную папку при запуске; это может замедлять первый старт. В процессе игры помощник завершает рабочий процесс с микрофоном и интерфейсом и оставляет наблюдатель за играми.

## Первое включение

1. Открой `Orbit Settings.exe`. Выбери микрофон и место появления островка; проверь анимацию кнопкой «Посмотреть анимацию».
2. В разделе «Микрофон» выбери `Vosk` для быстрой реакции или Whisper для более точного распознавания. Для **ответов** в разделе «ИИ и голос» выбери Gemini и укажи `GEMINI_API_KEY`, либо OpenAI и укажи `OPENAI_API_KEY`. Для Fish выбери бесплатную модель `S2.1 Pro Free`, введи `FISH_API_KEY` и `reference_id`; без ключа выбери `Piper` с локальным русским голосом. **Для микрофона ключ OpenAI не нужен.**
3. Нажми «Сохранить изменения» и «Запустить помощника». При первом запуске Vosk скачает малую русскую модель в `models\vosk-model-small-ru-0.22` (если её нет); Whisper загружает свою модель только при выборе Whisper. Piper скачает голос (~63 МБ) при первой озвучке и затем работает без интернета. Скажи «Орбит», «Окей, Орбит», «Хей, Орбит», «Привет, Орбит» или “Orbit”. Можно сразу добавить команду: «Орбит, открой сайт». Если произнесено только кодовое слово, следующая команда принимается 7 секунд.
4. Для остановки открой настройки и нажми «Остановить помощника». После изменения настроек перезапусти помощника этими кнопками.

Настройки (`config.toml`), ключи (`.env`) и голосовой образец хранятся в `%LOCALAPPDATA%\OrbitAssistant`. **API-ключи в `.env` не шифруются**: они не помещаются внутрь EXE, но доступны людям и программам с доступом к твоему профилю Windows. Не публикуй эти файлы. Сведения об ошибках фонового помощника — `%LOCALAPPDATA%\OrbitAssistant\orbit.log`. Для сборки из исходников данные остаются в папке проекта.

## Локальный Vosk/Whisper и шумоподавление

Vosk быстро распознаёт **всю фразу локально** и переиспользует ту же загруженную модель для кодового слова. Whisper точнее на сложной речи, но после фразы требует времени на обработку; при выборе Whisper Vosk дополнительно обслуживает раннюю активацию. Малой русской модели Vosk обычно нужно около 300 МБ ОЗУ при работе. Большая `vosk-model-ru-0.42` занимает гигабайты и не рекомендуется для ноутбука с 8 ГБ памяти. Текст команды передаётся выбранному облачному ИИ для ответа, поэтому для ответов нужен ключ Gemini или OpenAI. Fish Audio Free доступен по правилам добросовестного использования сервиса; Piper работает локально после скачивания модели. Edge TTS остаётся сетевым запасным голосом. Появление текста во время Piper приблизительное: Piper не возвращает метки времени отдельных слов.

Фильтр микрофона включён по умолчанию: он подавляет тихий фон и ослабляет звуки вне речевой полосы. При одновременном разговоре телевизор и твой голос одним микрофоном надёжно разделить нельзя. Дополнительная **проверка говорящего** остаётся локальной и необязательной: кроме модели кодового слова ей нужна отдельная модель голоса Vosk. Нажми в настройках микрофона «Скачать модели и записать мой голос». Короткие команды иногда отвергаются; запись твоего голоса на телевизоре тоже может пройти проверку. Голосовой образец остаётся на устройстве.

## Макросы и игровой режим

Координаты профилей MSI Center зависят от размера экрана и версии приложения. Укажи расположение **обеих** кнопок, проверь заголовок окна и только потом разреши управление в настройках. Программа проверяет активное окно перед кликом; голосовой ответ сам по себе не подтверждает фактическую смену режима MSI.

Укажи названия процессов игр (например, `cs2.exe`). Каждые пять секунд наблюдатель проверяет список процессов, закрывает микрофон и виджет при появлении игры и запускает их снова после закрытия игры. Точное потребление RAM зависит от Windows и установленных компонентов.

## Запуск из исходников

```powershell
python -m pip install --user -r .\requirements.txt
python .\settings_app.py
python .\assistant_app.py --demo
python .\assistant_app.py
```

Если выбрал Piper, можешь заранее скачать голос, чтобы первое голосовое сообщение не ждало загрузку:

```powershell
python -c "from orbit.speech import piper_voice_path; print(piper_voice_path('ru_RU-dmitri-medium'))"
```

`settings.bat` открывает настройки, `demo.bat` показывает островок, `run.bat` запускает обычный процесс. Для живых **ответов** нужен ключ выбранного ИИ: Gemini или OpenAI. Выбранный режим Vosk распознаёт всю команду локально. Fish/Edge начинают проигрывать звук по мере получения, Piper синтезирует его локально. При ошибках озвучки попробуется следующий голос. В `orbit.log` записываются время распознавания, ответа ИИ, первого звука и завершения озвучки. Если Windows блокирует создание дочернего `python.exe`, запускай `python -m orbit.worker` напрямую; такой запуск не включает игровой режим наблюдателя. Путь `orbit\worker.py` должен находиться рядом с `requirements.txt`, а не уровнем глубже.

Если голосовая активация молчит, запусти `python -m orbit.recognition` из корня проекта и скажи «Орбит, привет». Диагностика покажет выбранный микрофон, уровень сигнала, число выделенных фраз, распознанный текст и сработавшее кодовое слово. Если фраз нет, выбери другое устройство или временно выключи шумоподавление. Если модель не загрузилась, вывод покажет ошибку установки или первого скачивания. При запуске через приложение сведения о готовности микрофона и ошибках записываются в `orbit.log` рядом с исходниками или в `%LOCALAPPDATA%\OrbitAssistant\orbit.log` для EXE.

Сборка не была проверена на твоём Windows из этой среды. Если запуск EXE даст ошибку, загляни в `orbit.log` и пришли текст ошибки. Если `.exe` пока не собирается из-за отсутствующего `pip`, само приложение настроек можно проверить после установки зависимостей командой `python settings_app.py`.
