ORBIT: быстрый Vosk, локальный Whisper и бесплатная озвучка

1. Распакуй архив в корень своего проекта, где находятся assistant_app.py
   и settings_app.py. Согласись на замену файлов. Архив не трогает твои
   config.toml и .env: положение виджета, настройки и ключи сохраняются.
   Старые значения whisper-1 и gpt-transcribe автоматически принимаются
   как локальная модель Base; при сохранении настроек значение обновится.
2. Открой PowerShell в папке проекта и установи зависимости:
      python -m pip install -r .\requirements.txt
3. Открой настройки: python .\settings_app.py
   Выбери Vosk (быстро, меньше точность) или Whisper Tiny/Base/Small.
   В разделе «ИИ и голос» выбери Fish Audio Free или локальный Piper.
   Платная модель Fish S2.1 Pro может ответить HTTP 402.
   Если в старых настройках выбрана она, при 402 будет попытка
   использовать модель s2.1-pro-free. Для неё по-прежнему нужен ключ
   Fish и reference_id; возможны лимиты бесплатного режима.
   Piper скачивает русский голос (~63 МБ) один раз, дальше работает
   без сети. Выбери Дмитрия или Ирину в конфигураторе.
   Чтобы скачать голос Дмитрия до первого ответа:
      python -c "from orbit.speech import piper_voice_path; print(piper_voice_path('ru_RU-dmitri-medium'))"
   Для микрофона OPENAI_API_KEY НЕ НУЖЕН. Если хочешь ответы Gemini,
   укажи GEMINI_API_KEY; для ответов OpenAI укажи OPENAI_API_KEY.
4. Обычный запуск: python .\assistant_app.py
   Если Windows запрещает дочерний процесс Python, запускай напрямую:
      python -m orbit.worker
   Для проверки дизайна без микрофонного распознавания и ключей:
      python -m orbit.worker --demo

Если на «Орбит» нет реакции, проверь голосовой тракт одной командой:
      python -m orbit.recognition
Говори «Орбит, привет» сразу после приглашения. Команда покажет имя
микрофона, уровень звука, число выделенных фраз и текст выбранной модели.
Если фраз 0 — выбери другой микрофон или отключи фильтр шума. Если
распознанное слово не «Орбит», сначала попробуй «Окей, Орбит» и Tiny/Base.
Если возникает ошибка скачивания Whisper/Piper — нужен доступ к Hugging Face
при первом запуске. Для Vosk нужен доступ к alphacephei.com. Лог лежит в orbit.log
в папке проекта (для EXE — в %LOCALAPPDATA%\OrbitAssistant\orbit.log).

Модель распознавания скачивается один раз, затем работает без интернета
и без тарифа OpenAI Audio API. В Vosk режиме Whisper вообще не загружается,
его малая русская модель выполняет и активацию, и обработку полной фразы.
Vosk заметно быстрее, но уступает Whisper по точности свободной речи.
Whisper Tiny/Base/Small по-прежнему доступны. Ни Vosk, ни Whisper
не гарантируют общий процесс в пределах 50–70 МБ ОЗУ.

Для мгновенного появления островка добавлен Vosk только для кодового слова.
Если малая русская модель отсутствует, она скачивается при первом запуске.
Если загрузка не удалась, остаётся прежнее распознавание Whisper.
В настройках можно отключить быструю активацию ради экономии памяти;
малая модель Vosk может занимать около 300 МБ при работе.
В режиме Whisper он по-прежнему распознаёт полную команду. Fish Audio и Edge TTS
теперь
начинают воспроизведение при первом полученном куске голоса, а не после
всех кусков. Piper локально отдаёт аудиофрагменты во время синтеза.
В orbit.log видны задержки Vosk/Whisper, ИИ и первого звука отдельно.

Кодовые фразы: Орбит; Окей, Орбит; Хей, Орбит; Привет, Орбит;
Orbit; Okay, Orbit; Hey, Orbit; Hello, Orbit. Можно добавить команду
в ту же фразу. После одной кодовой
фразы есть семь секунд на отдельную команду.

Проверка «только мой голос» остаётся необязательной. Для неё нужна
дополнительная модель говорящего; кодовое слово использует обычную модель.
